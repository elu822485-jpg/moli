本次调整

  • 附加预设精简 — 移除了旧版「文风塑造指令」与「世界书：扮演规范 + 好感度」的勾选项。主生成流程更加干净，专注人设本身。
  • 四项扩展生成 — 全部移动到「扩展生成」板块，在生成人设之后使用。读取当前展示区的人设，在此基础上生成对应扩展内容。

扩展生成板块 · 四项功能

  • NPC 关系网扩展 — 生成 4–12 名彼此关联、立场各异、拥有独立秘密的 NPC。
  • User 面具生成 — 设计一个能自然进入该角色人生的 User 身份，保留 User 主体权。
  • 扮演规范 + 好感度系统 — 将人设转换为可长期运行的扮演规范、语言行为规范，以及 -100 ～ 100 的好感度动态系统。
  • 专属小说体文风 — 从人设中自动提炼只属于该 Char 的叙事语言、节奏、意象与情绪表达方式。

公告栏改进

  • 新增 不再提示 按钮 — 点击后本次公告不再自动弹出。
  • × 与「我知道了」仅关闭本次，下次打开仍会显示。
